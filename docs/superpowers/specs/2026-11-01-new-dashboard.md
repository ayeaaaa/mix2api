# mix2api 新面板设计说明

## 目标

在不改动后端 API 的前提下，把现有单页看板重做成一套现代、分区清楚的响应式面板。新面板先挂在 `/next`，旧 `/` 保持可用；功能对齐、桌面与手机验收通过后，再把 `/` 切到新面板并删除旧壳。

## 视觉方向

已选定方向 A「清透中性」：

- 浅灰页面底、白色内容面板、细边框、低阴影；
- 单一靛蓝强调色，颜色只用于主操作、选中态和状态；
- 系统无衬线字体，标题紧字距，正文 12–14px；
- 桌面左侧 8 区导航，顶部状态栏；
- 手机底部 5 项导航 + 「更多」抽屉；
- 深色主题沿用同一套 token，不另做一套布局。

## 信息架构

| 新导航 | 页面 key | 内容 |
| --- | --- | --- |
| 总览 | `overview` | 出口卡片、积分/账号/模型汇总、调度器状态、最近请求 |
| 网关 | `gateway` | 网关模型清单、模型勾选、能力/上下文/思考档位/倍率 |
| 账号 | `accounts` | CodeArts 账号、WorkBuddy 账号、当前禁用、签到与活跃记录 |
| 用量 | `analytics` | 时间范围、KPI、Token 时序、最近请求、工作回溯、用量明细、剩余用量、积分历史 |
| 自动化 | `tasks` | 国际版每日活跃、国内版任务与福利、后台调度器 |
| 智能体 | `agents` | 连接信息、本机客户端、其他客户端、一键配置/还原 |
| 设置 | `settings` | 现有全部设置项，按基础 / API 与出口 / 模型与定价 / 自动化 / 稳定性 / 日志与系统分组，一次只显示一组 |
| 日志 | `logs` | 级别/标签/搜索、自动刷新、清空、导出、落库状态 |

账号在新面板中固定为独立页；设置里的「账号独立成一个页签」在新壳中不再显示，避免与固定导航冲突。旧壳仍按原设置工作。

## 实现策略

- 保留现有页面 DOM、元素 ID 与业务 JS，避免重写 API 调用、轮询、i18n、弹窗和测试钩子。
- 新壳只做三件事：重排导航、重设布局与样式、在页面切换时同步新导航状态。
- 现有 `switchMainTab()` 扩展 `overview`，并把原 `pageGateway` 改名为 `pageOverview`；模型清单独立成新的 `pageGateway`。
- 调度器状态条从总览移到自动化页；账号区固定拆到账号页。
- 新样式全部限定在 `html[data-ui="next"]` 下，旧 `/` 不受影响。
- `/next` 与 `/` 返回同一份 HTML，由首帧脚本根据路径打上 `data-ui="next"`。

## 功能对齐清单

### 总览
- 国际版 / 国内版 / CodeArts 出口卡片：可用积分、总积分、账号数、Key 数、默认出口标记、当前视图标记、离线标记。
- 网关默认出口切换。
- 汇总卡：账号、模型、今日请求、估算花费/成功率等现有 `#cards` 指标。
- CodeArts 独立汇总卡。
- 调度器状态与「立即巡检保活 / 暂停调度」。
- 最近请求：10/20/50/100 条切换、分页、上一页/下一页、状态/模型/账号/Token/延迟/价格。

### 网关
- 模型清单：模型 ID、名称、消费倍率/优惠、能力、上下文窗口、最大输出、思考档位、默认采样参数。
- 模型勾选：全选、全不选、反选、单模型勾选，保存到 `agent_models`。
- 清单来源横幅、刷新模型清单、当前视图标签、可用模型数。
- 价格估算列/提示。

### 账号
- CodeArts：OAuth 添加、全员签到、保活、刷新、账号行、积分/健康/冷却、备注、任务、测试、重新登录、启用/停用、删除、代理槽、清冷却、积分刷新。
- WorkBuddy：账号列表、添加、API Key 导入、Buddy 签到、国际版每日活跃、网页通道打卡、扫描桌面客户端、签到记录、导入/导出、一键刷新积分/凭证、一键测试、一键分配代理、一键切换出站身份、全部启用/停用。
- 当前禁用列表。
- 签到与活跃记录：区间/任务/结果/账号筛选、加载更多、上限 1000 行。

### 用量
- 今日/近 3 日/本周/本月/近 30 天/全部。
- KPI：Token、请求数、生成速度、缓存命中率、API 等价、成功率。
- Token 时序：Token/请求数/吞吐量切换。
- 最近请求活动流。
- 工作回溯热力图与年度统计。
- 用量明细：按模型/账号/API Key，列选择。
- 剩余用量估算：国际版/国内版预算、账号×模型明细、撞线样本。
- 积分扣减历史。
- 模型性能、按 Key 用量、价格提示。

### 自动化
- 国际版每日活跃福利：打卡、未活跃一键打卡。
- 国内版任务与福利：Buddy 签到、一键做任务领积分、猫猫旅行、连登管家与抽奖。
- 后台调度器：状态、下次执行时间、立即巡检、暂停/恢复。

### 智能体
- 连接信息：Base URL、API Key、默认模型、复制。
- 本机客户端：Claude Code、Codex、OpenCode、DSH、Crush、ZCode 检测、配置、还原、外部修改提示。
- 其他客户端：配置器 CLI 命令、复制。
- 模型清单选择、API Key 选择、网关地址。

### 设置
- 面板访问密码、界面语言、顶部页签显示、账号独立页签（新壳隐藏）、面板窗口限高。
- API Key 增删改、出口绑定、复制/显示。
- CodeArts 接入：保存、测试连接、刷新积分。
- 账号代理槽：自动发现、添加、保存、测试。
- 账号限额：保留积分、每日 Token、每日积分、按模型 Token，全局/分版本。
- 模型价格估算：开关、汇率、刷新、手填映射、未定价清单。
- Anthropic Messages 开关。
- 思考等级挡位映射。
- 按 API Key 过滤模型、只列出可用模型、免费额度耗尽回退。
- 自动切换出站身份、数据用途声明、出站身份版本号。
- 国际版每日活跃打卡：时间、模型、提示词、保存/恢复。
- 全局提示词、本地网络工具。
- 剩余用量优先调度、跨出口回退、模型额度窗口探针、出口级瞬时失败退避、模型额度定时主动查询、用量聚合保留窗口、上游响应头超时、账号级并发上限、更稳的会话粘滞键。
- 日志落库。
- 更新：检查、安装、版本回退。
- 运行信息、退出面板登录。

### 日志
- 级别/标签/搜索筛选。
- 自动刷新、清空、导出。
- 内存/落库模式、库容量。
- 新窗口打开运行日志、关闭网关服务。
