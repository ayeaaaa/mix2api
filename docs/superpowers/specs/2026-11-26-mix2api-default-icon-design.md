# mix2api 默认图标设计

## 目标

给 mix2api 控制台加一个默认品牌图标，让新部署不再显示空 favicon 和字母 `m` 占位。

## 已确认方向

用户选择 **1 + 3**：字母 M 品牌字标 + 可独立使用的 App 图标。视觉方案选择预览中的 **C. 负形 M**：

- 512×512 圆角方形
- 靛蓝 → 青色渐变底
- 深墨蓝 M 负形，左右底端各一个浅色路由端点
- 小尺寸 16px 下仍能识别 M
- 纯 SVG，无外部图片依赖

## 行为

- `site_icon` 为空时，侧栏品牌位和浏览器标签使用内置默认图标。
- 设置里上传/填写自定义图标后，自定义图标覆盖默认值。
- 设置页的图标预览在未自定义时显示默认图标，状态显示“默认图标”。
- `/favicon.svg` 和 `/favicon.ico` 都由程序直接提供，不再 404。
- 不改变 API、健康检查、更新检查或账号逻辑。

## 非目标

- 不做 Windows/macOS 安装包图标。
- 不改经典 UI 顶栏的三条横线标记。
- 不新增第三方图标 CDN 或运行时依赖。

## 验收

- 浏览器标签显示默认图标。
- 侧栏 31px 图标清晰可辨，和自定义图标互不干扰。
- `/favicon.ico` 返回 200 且内容类型正确。
- 自定义 `site_icon` 仍然覆盖默认图标，恢复默认品牌后回到内置图标。
- dashboard hash/oracle 更新，`make check` 和 `make race` 通过。
