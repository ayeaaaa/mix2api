# mix2api v2 CodeArts Provider Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the CodeArts Provider module with v1.6.5 behavior: OAuth PKCE+DPoP, token refresh, model discovery, chat/SSE, account pool, credits/check-in, zero-credit failover, manual-disable persistence, expiring-credit priority, and all `/codearts/*` admin routes.

**Architecture:** `internal/providers/codearts` owns all CodeArts behavior and registers its routes. It uses `internal/core` for config/storage/transport/state only. It must not import WorkBuddy/Raccoon.

**Tech Stack:** Go standard library, `crypto` for PKCE/DPoP/JWT handling, `net/http`, `httptest`.

**Spec:** `docs/superpowers/specs/2026-11-08-mix2api-v2-design.md`
**Foundation plan:** `docs/superpowers/plans/2026-11-08-v2-foundation-raccoon.md` (Provider/Route/interfaces)

## Global Constraints

- v1.6.5 `app/wb_codearts.py`, `app/wb_codearts_crypto.py`, `app/tests/_fake_codearts.py` are the behavior reference.
- All credentials remain local; never return tokens to panel responses or logs.
- Preserve `/codearts/*` paths/status/JSON shapes and CodeArts auth/state file formats.
- Manual disable survives token refresh, re-login and model discovery.
- Known zero-credit accounts are not picked; credit-exhausted 400 fails over; all-exhausted returns readable 400.
- Expiring-credit priority defaults on and only affects account selection.
- No real upstream in automated tests.

## Review Focus

1. Zero-credit/manual-disable race — refresh/model discovery must not resurrect a parked account.
2. DPoP/PKCE correctness — headers, nonce/key handling, refresh_token rotation.
3. SSE concurrency retry and credit-exhausted failover must release each account exactly once.
4. Model catalog availability and lowercase `deepseek-v4.1-flash-1017` in agent picker.
5. Check-in credits clearing zero-credit snapshots and 24h expiry semantics.
