# mix2api v1.2.0

功能版本：合并 WorkBuddy 上游 v1.10.4，补齐成长任务、模型目录和计费快照，同时保留 mix2api 的 CodeArts 与新面板能力。

## 这个版本做了什么

- **同步上游 v1.10.4 成长任务**：新增全能任务、Buddy 开盲盒、小程序链式任务与动态专家任务；猫猫旅行流程会顺带处理 Buddy 盲盒。
- **同步模型目录与价格快照**：`wb_catalog.py`、`wb_pricing.py`、`pricing/pricing.json`、`wb_modelsdev.py` 对齐上游 v1.10.4。
- **新增/更新模型**：`gpt-6.1-sol`、`gpt-6-sol`、`gpt-6-luna`、`gemini-3.8-flash`、`kimi-k3.1-pro`、`kimi-k3.1-pro-highspeed`、`minimax-m3.1-flash`、`deepseek-v4.1-flash-sg` 等。
- **目录筛选修正**：`-sg` / `-x` 变体只在同名基名也存在时才丢弃；上游已不再列出的基名会保留 `-sg` 版本。
- **非聊天模型排除**：`hy-image-3.5`、`kling-video-v3` 不再进入聊天模型列表。
- **保留 mix2api 能力**：CodeArts 视觉输入、账号备注/任务/测试/积分刷新、独立签到保活、三出口路由、新面板 `/` 与旧面板 `/classic`。
- **保留安全修复**：CodeArts UID inline handler 安全字符集、429 绝对恢复时刻。

## 升级

- 直接替换镜像或代码即可，无数据迁移；默认端口仍是 `58675`。
- 默认 `/` 新面板，`/classic` 旧面板。
- 客户端 API 地址、Key、模型 ID 不变。
- 新增模型会按当前出口和账号权限自动出现在模型列表中。

- 246 个测试套件全过。
