# mix2api v1.1.0

新面板成为默认界面，同时回移上游 `workbuddy2api-hub` v1.10.x 的一批修复。

## 这个版本做了什么

### 新面板（默认 `/`）

- 全新「清透中性」界面：桌面左侧 8 个功能区，手机底部 5 项 + 「更多」抽屉。
- 分区：总览 / 网关 / 账号 / 用量 / 自动化 / 智能体 / 设置 / 日志。
- 设置页拆成 6 个子页：基础、API 与出口、模型与定价、自动化、稳定性、日志与系统。
- 账号固定为独立页；网关模型清单独立成页；调度器移到自动化页。
- 页面内导航改成顶部横向胶囊条，保留「回到顶部」。
- 顶部页签显示设置会同步到新导航；网关页新增出口切换。

### 登录与安全

- 登录框新增「保持登录（7 天）」：勾选后关浏览器也不用重新输密码；不勾选仍只保留当前标签页。
- 修改密码时「当前密码不正确」不再被当成会话失效：不会退出登录，只提示密码未修改。
- 改密后新的会话令牌会沿用当前的「保持登录」选择。

### 品牌与更新

- 面板标题、登录框、GitHub 链接统一为 mix2api。
- 运行信息显示：项目 `mix2api`、当前版本 `1.1.0`、更新源 `ayeaaaa/mix2api`。
- 版本检查与便携版更新包改为 mix2api 仓库和 `mix2api-<版本>-deploy.zip`。
- HTTP `Server` 头改为 `mix2api/1.1.0`。

### 上游修复回移（workbuddy2api-hub v1.10.x）

- CodeArts 补发 `x-ot-session-id` / `user-session-id` / `x-ot-trace-id`，修掉会话名额被历史请求占满后的排队与 `TM.00001041`。
- CodeArts 的 Key 账号白名单与模型限制在进上游前生效。
- CodeArts SSE 首个事件保留。
- OAuth 回调 `redirect` 必须属于 CodeArts 门户，拒绝带凭据的跳转；回调 HTML 转义。
- `normalize_tools` 丢弃上游不接受的 `function.name`，修掉 400 / code 11133。
- 设置页新增「单请求体上限」（1–256 MB），保存立即生效。
- Key 选择器显示账号备注；活动状态区分「无本地记录」；删除重复的「上游响应头超时」卡片；活动流跨天补日期。
- 模型 429 增加 `X-RateLimit-Reset` / `X-RateLimit-Reset-At` 与正文 `reset_at`。

## 升级

- 直接替换镜像或代码即可，无数据迁移；默认端口仍是 `58675`。
- 默认打开 `/` 就是新面板；旧界面保留在 `/classic`，可随时回退。
- 如果之前用 `/next` 收藏，地址仍然可用。
- 客户端 API 地址、Key、模型 ID 不变。

## 验证

- 245 个测试套件全过。
- 新面板桌面/手机 Playwright 检查通过。
- CodeArts 会话头、OAuth 跳转校验、工具名校验、请求体上限、改密不退出等均有回归测试。

## Docker 镜像

已发布到 GitHub Container Registry，支持 `linux/amd64` 与 `linux/arm64`：

```bash
docker pull ghcr.io/ayeaaaa/mix2api:v1.1.0
docker pull ghcr.io/ayeaaaa/mix2api:latest
```

直接运行：

```bash
docker run -d --name mix2api -p 58675:58675 \
  -v "$PWD/data/accounts:/app/accounts" \
  -v "$PWD/data/usage:/app/usage" \
  ghcr.io/ayeaaaa/mix2api:v1.1.0
```

- GitHub 自动生成的 Source code 包含完整仓库（含 `reference/codearts2api/`）。

## English summary

`mix2api` v1.1.0 makes the new dashboard the default at `/` (the old shell remains at `/classic`) and ports the important `workbuddy2api-hub` v1.10.x fixes: stable CodeArts `x-ot-session-id` sessions, per-key CodeArts account/model restrictions, preserved first SSE event, OAuth redirect validation, tool-name validation, a panel-adjustable request-body limit, and absolute 429 reset headers on model throttles. Login can now be remembered for seven days, and changing the panel password with a wrong current password no longer drops the session. All existing API endpoints, keys and data remain compatible; 245 test suites pass.
