# mix2api v1.6.6

网页通道身份对齐、CodeArts 稳定性修复，以及 WorkBuddy 封禁/模型别名/请求清洗/Responses 回放的一批兼容修复。

## 这个版本做了什么

### 网页通道

- 按账号稳定派生浏览器画像（UA / Accept-Language / `sec-ch-*`），不再所有账号共用一个 UA。
- 建会话 body 对齐官方网页端：`agents` + `addonSelection` + 三个 `workbuddy-builtin` 插件 + `extraInfo`。
- 请求头补 `X-Request-ID`，`Accept` 改为 `application/json`。
- ACP 补齐 `session/new`、`session/set_mode`、`session/set_config_option`，`session/prompt` 带完整 `_meta`。
- 提示词前随机停顿 2–8 秒，可用 `WB_WEB_HUMAN_DELAY_MIN` / `WB_WEB_HUMAN_DELAY_MAX` 调整或关闭。

### CodeArts

- 上游模型 ID 大小写不一致时，在同一账号上自动重试另一种拼写并缓存成功拼写。
- preflight 跳过 role-only 首帧，模型权限错误仍能在流开始前被识别。
- SSE 内嵌「积分已耗尽」映射为可恢复 429，账号冷却 600 秒并换号。
- terminal credential error 不再清除操作者的手动停用状态。

### WorkBuddy

- `11140` 改为持久封禁：停用 API 派发和自动任务，重启 / 刷新 token / 重新导入 / 成功探测都不会解封，只有手动启用才清除。
- 国际版 `deepseek-v4.1-flash` 出站映射到 `deepseek-v4.1-flash-sg`；客户端目录、响应和 usage 的 `requested_model` 仍保留逻辑 ID。`WB_INTL_MODEL_ALIAS=0` 可关闭。
- 完整 11151 空文本守卫：列表、`null`、缺失 text、字符串嗅探出的 parts 都会补位。
- billing header / Claude Code / Codex / DSH / OmO 指纹清洗；工具描述也纳入清洗范围。
- `reasoning_content` 镜像到旧模型读取的 `reasoning` 字段。
- Responses 历史推理保真：相邻 reasoning 合并、assistant 内联 reasoning/tool_calls 保留、工具边界清空 pending reasoning。
- DSH `.credentials.yaml` 的 flow-map `refs` 支持增改。

### 其他

- 控制台 profile 同时接受顶层和 `{"code":0,"data":{...}}` 包装。
- 桌面身份升级到 `5.9.4` / `CLI 2.165.0`。
- 面板响应增加 `X-Robots-Tag: noindex, nofollow`。
- CN Kimi 工具 schema 发送前内联 `$ref` / `$defs`。

## English summary

`mix2api` v1.6.6 aligns the web-channel browser identity and ACP request shape with the official web client, fixes CodeArts model-ID casing and SSE credit exhaustion handling, makes upstream 11140 a persistent account ban, routes intl `deepseek-v4.1-flash` to `-sg`, completes the 11151 empty-text guard, sanitizes billing headers and tool descriptions, preserves reasoning replay for Responses, and adds DSH flow-map, profile-wrapper, identity-version, noindex and CN Kimi schema fixes. All 286 suites pass (213 Python + 73 JS).
