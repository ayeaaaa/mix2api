# mix2api v1.0.2

v1.0.1 之后的补丁版：CodeArts 自动签到默认开启。

## 这个版本做了什么

- **CodeArts 自动签到**：跟随国内版签到时段（默认 09:00 / 21:00），只跑已启用且未冷却的账号；当天成功一次后不重复，失败会在下一个时段或手动「立即巡检」时重试。
- **默认开启**：设置页「CodeArts 接入」新增「每天自动签到」开关，默认勾选；旧 `settings.json` 没有 `auto_checkin` 时按开启处理，无需迁移。
- **调度器可见**：`/scheduler` 返回 `codearts_checkin`，运行状态文案会显示「CodeArts 自动签到」。
- **只有 CodeArts 账号也能跑**：调度器不再因为 WorkBuddy 账号列表为空而跳过整轮巡检，CodeArts 签到仍会执行。
- **手动入口保留**：看板「签到 / 全员签到」和管理端点 `/codearts/accounts/checkin` 不变。

## 升级

- 直接替换镜像或代码即可，无数据迁移；默认端口仍是 `58675`。
- 已有 CodeArts 账号会自动纳入每日签到；不想自动跑就在设置页取消「每天自动签到」。
- 签到成功状态按账号持久化，重启后当天不会重复签到；失败状态会保留，下一时段可重试。

## 验证

- 243 个测试套件全过。
- 本地实测：手动触发巡检后，新增的 CodeArts 账号自动签到成功；4 个账号全部显示已签到。
- 调度器状态显示 `codearts_checkin: true`，下次排程正常。

## Docker 镜像

已发布到 GitHub Container Registry，支持 `linux/amd64` 与 `linux/arm64`：

```bash
docker pull ghcr.io/ayeaaaa/mix2api:v1.0.2
docker pull ghcr.io/ayeaaaa/mix2api:latest
```

直接运行：

```bash
docker run -d --name mix2api -p 58675:58675 \
  -v "$PWD/data/accounts:/app/accounts" \
  -v "$PWD/data/usage:/app/usage" \
  ghcr.io/ayeaaaa/mix2api:v1.0.2
```

或用本包里的 `deploy/docker-compose.image.yml`：

```bash
cd deploy
docker compose -f docker-compose.image.yml up -d
```

## English summary

`mix2api` v1.0.2 enables daily CodeArts check-in by default. It follows the existing check-in slots (09:00 / 21:00), runs only enabled and non-cooling accounts, skips an account once it has succeeded today, and retries failures at the next slot or a manual sweep. The dashboard exposes a "daily auto check-in" switch (on by default), and the scheduler works even when there are no WorkBuddy accounts. The multi-arch image is published as `ghcr.io/ayeaaaa/mix2api:v1.0.2` and `:latest`.
