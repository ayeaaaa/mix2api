# mix2api v1.5.0

接管 WorkBuddy2API-Hub 的最终版 v2.0.0，保留 mix2api 品牌、新 UI、媒体生成和 CodeArts 官方倍率。

上游已于 2026-11-06 发布 v2.0.0 后停止维护；自本版本起，后续功能、修复与发布都在 mix2api 仓库进行。

## 上游更新

- 用量聚合缓存补写：checkpoint 写盘被跳过时按类节流告警，并登记后台异步补写（30 秒起指数退避，封顶 15 分钟）；新增 64MB 落后告警和按 pid 隔离临时文件
- 设置页分组语言切换修复：正體中文 / 英文界面下按 i18n 原文归类，不再整页区块被隐藏
- 补上「选择网页活跃提示词」到自动化分组

## mix2api 变更

- 文档补齐：`docs/CHANGELOG.md` 同步到 v2.0.0，补入媒体实现 / 计划 / 测试计划与 11-128 排障文档
- 更新检查默认仓库改为 `ayeaaaa/mix2api`；仓库已公开，匿名可读，配置 `GITHUB_TOKEN` 只是提高 API 配额
- 根目录新增测试 CI（`.github/workflows/tests.yml`）
- `UPSTREAM.md` 改为维护状态说明，不再保留同步上游流程

## mix2api 保留

- mix2api 品牌与 `WorkBuddy` 产品文案分离
- `/` 新 UI、`/classic` 旧壳
- 不使用 Alibaba 默认配色，默认 Claude 主题
- 媒体生成模块
- CodeArts 官方 10 个模型与积分倍率（含 DeepSeek 高峰/错峰）
- CodeArts `credits_auto_claim` 默认开启
- 本地部署端口 `58675`

## 升级说明

- 版本号：`mix2api/1.5.0`；镜像 `ghcr.io/ayeaaaa/mix2api:v1.5.0`
- 面板“检查更新”现在查询 mix2api 自己的 Release；仓库公开后无需 token，配置后只是提高 API 配额
- 配置与账号数据格式未变，可直接覆盖升级

## 验证

- 全量测试套件通过
- 本地容器重建后 `/health` 返回 `mix2api/1.5.0`
- `/` 与 `/classic` 正常
- 网关到上游的真实请求正常返回

## English summary

`mix2api` v1.5.0 takes over the final WorkBuddy2API-Hub v2.0.0 release (usage-cache retry/backfill, settings-group i18n fix, docs and troubleshooting guides) while preserving mix2api branding, the `/classic` shell, media generation, and the official CodeArts model credit multipliers. The upstream project ended at v2.0.0; mix2api continues maintenance from this release. Update checks now target the public `ayeaaaa/mix2api` repository (`GITHUB_TOKEN` is optional and only raises the API quota), and a root test workflow was added.
