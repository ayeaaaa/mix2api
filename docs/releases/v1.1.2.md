# mix2api v1.1.2

补齐 429 的绝对恢复时刻：登录限流和 CodeArts 透传出口也带 `X-RateLimit-Reset` / `X-RateLimit-Reset-At`。

## 这个版本做了什么

- **登录限流 429**：面板登录连续失败触发的 429 现在同时返回 `Retry-After`、`X-RateLimit-Reset`、`X-RateLimit-Reset-At`，正文带 `reset_at`。
- **CodeArts 透传 429**：CodeArts 上游 429 不再统一映射成 502；保留 429 状态，并从上游正文里的墙钟解析绝对恢复时刻；OpenAI / Anthropic 两种错误信封都带恢复头。
- **通用错误出口**：`_error()` / `_anthropic_error()` 现在统一处理 429 的绝对时刻；头只在 429 响应上出现，非 429 响应一个字节都不多发。
- **keep-alive 隔离**：额外响应头按请求重置，上一轮 429 的恢复时刻不会漏给同一连接的下一个响应。

## 升级

- 直接替换镜像或代码即可，无数据迁移；默认端口仍是 `58675`。
- 默认 `/` 新面板，`/classic` 旧面板。
- 客户端 API 地址、Key、模型 ID 不变。
