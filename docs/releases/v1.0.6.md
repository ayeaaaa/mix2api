# mix2api v1.0.6

v1.0.5 之后的补丁版：把 CodeArts 剩余的高优先级对齐项一次补齐。

## 这个版本做了什么

- **请求参数透传**：CodeArts chat 现在透传 `stop`、`response_format`、`frequency_penalty`、`presence_penalty`、`seed`。这些字段上游已实测接受，之前被网关的窄白名单丢掉了。
- **模型元数据补齐**：`/v1/models` 输出 `context_length`、`max_input_tokens`、`max_output_tokens`、`max_completion_tokens`、`max_output`，以及 `supports_tool_calls` / `capabilities.tool_calls`。上游 builtin 没给上下文/输出上限时，用同名 WorkBuddy 目录兜底。
- **错误语义**：非视觉模型收到图片时返回 400，并提示可用 `YYLS/Qwen3-VL-235B` / `YYLS/kimi-k2.6-vl`；不再把上游的 `not multimodal` 吞成 502。
- **自动保活**：调度器 22:00 与 WorkBuddy 一起执行 CodeArts Token 保活；CodeArts 签到仍跟随签到时段。
- **账号运营**：CodeArts 账号表新增备注、任务开关、单账号测试。任务开关允许「API 停用但继续签到」；测试会刷新 token、拉模型并查积分。
- **统一目录**：`/v1/models?realm=all` 现在同时包含 WorkBuddy 模型和 `YYLS/` CodeArts 模型。
- **活动历史**：CodeArts 签到写入 `/activity/history`，区域显示 `CodeArts`，可按任务/结果/账号筛选。

## 升级

- 直接替换镜像或代码即可，无数据迁移；默认端口仍是 `58675`。
- 已有 CodeArts 账号的备注/任务开关默认：备注为空、任务开启。
- 如果客户端缓存了旧的 `/v1/models`，刷新一次即可看到新增的限额/工具字段。

## 验证

- 243 个测试套件全过。
- 实测 `stop` 生效（输出在 `B` 前停止）。
- 实测 `YYLS/GLM-5.2` 带图片返回 400，并提示可用视觉模型。
- 实测 `/v1/models?realm=codearts` 的 GLM-5.2 / deepseek-v4.1-flash 带上下文/输出上限。
- 实测账号备注、任务开关、单账号测试、签到进活动历史。
- 实测 `realm=all` 同时返回 WorkBuddy 模型和 `YYLS/` 模型。

## Docker 镜像

已发布到 GitHub Container Registry，支持 `linux/amd64` 与 `linux/arm64`：

```bash
docker pull ghcr.io/ayeaaaa/mix2api:v1.0.6
docker pull ghcr.io/ayeaaaa/mix2api:latest
```

直接运行：

```bash
docker run -d --name mix2api -p 58675:58675 \
  -v "$PWD/data/accounts:/app/accounts" \
  -v "$PWD/data/usage:/app/usage" \
  ghcr.io/ayeaaaa/mix2api:v1.0.6
```

或用本包里的 `deploy/docker-compose.image.yml`：

```bash
cd deploy
docker compose -f docker-compose.image.yml up -d
```

## English summary

`mix2api` v1.0.6 completes the CodeArts alignment pass: chat forwards `stop`, `response_format`, penalties and `seed`; `/v1/models` exposes context/output aliases and tool capability (with a same-name WorkBuddy catalog fallback for missing limits); non-vision image requests return a clear 400; the scheduler refreshes CodeArts tokens at 22:00; accounts gain notes, a task toggle and a per-account test; `realm=all` includes `YYLS/` models; and CodeArts check-ins land in activity history. The multi-arch image is published as `ghcr.io/ayeaaaa/mix2api:v1.0.6` and `:latest`.
