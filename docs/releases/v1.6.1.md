# mix2api v1.6.1

小浣熊入口可见性补丁：不启用也能看到「添加账号」，首次导入后自动启用并切到小浣熊视图。

## 这个版本做了什么

- **小浣熊卡片常显**：未启用时网关页仍显示「小浣熊 (Raccoon)」卡片，并标注「未启用 · 点击添加」。点击卡片直接打开添加账号弹窗，不再需要先到设置页手动启用。
- **导入后自动进入视图**：第一次成功导入 `auth.json`（或完成回环 OAuth）后，出口自动启用并切到小浣熊账号页，导入结果立即可见。
- **账号页入口常显**：「账号」页的小浣熊按钮不再依赖出口已启用；未启用时点击同样打开添加账号弹窗。
- **设置页快捷入口**：设置 →「小浣熊接入」新增「添加小浣熊账号」按钮，和保存/测试放在一起。
- **纯 UI 补丁**：Raccoon 的导入、OAuth、账号池、模型目录、聊天 SSE、用量归因和代理槽协议均未改动。

## Docker 镜像

```bash

docker run -d --name mix2api -p 58675:58675 -e PORT=58675 \
  -v "$PWD/data/accounts:/app/accounts" \
  -v "$PWD/data/usage:/app/usage" \
  ghcr.io/ayeaaaa/mix2api:v1.6.1
```

## English summary

`mix2api` v1.6.1 is a UI-only patch for the Raccoon exit. The Raccoon card and account entry are now visible even before the realm is enabled, marked "not enabled - click to add"; clicking opens the add-account modal. A successful first `auth.json` import (or loopback OAuth) auto-enables the realm and switches to the Raccoon view. The provider protocol, account pool, model catalog, chat SSE, usage attribution and proxy-slot behavior are unchanged. All 284 test suites pass; the multi-arch image is published as `ghcr.io/ayeaaaa/mix2api:v1.6.1` and `:latest`.
