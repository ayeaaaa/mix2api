# mix2api v1.6.2

恢复小浣熊出口的「设置启用」门控：启用后才出现卡片和账号入口；v1.6.1 的授权回调修复保留。

## 这个版本做了什么

- **恢复设置启用门控**：小浣熊卡片、账号页「小浣熊」按钮重新改为在「设置 → 小浣熊接入」勾选「启用小浣熊出口」后才出现。未启用时不再常显。
- **设置提示更明确**：启用项旁新增说明「启用后网关页才会出现小浣熊卡片和『添加账号』入口」。
- **保留授权修复**：v1.6.1 已把浏览器回环回调改为官方要求的 `/auth/callback`，本版继续使用；旧 `/raccoon/oauth/callback` 仅保留一个发布周期的兼容入口。
- **纯 UI 补丁**：Raccoon 的导入、账号池、模型目录、聊天 SSE、用量归因和代理槽协议未改动。

## 验证

- 284 个测试套件全过（212 Python + 72 JS）。
- 看板 JS 覆盖：未启用时卡片/账号按钮隐藏、设置页提示存在、启用后正常显示和切换；CodeArts/WorkBuddy 入口回归通过。
- 本机容器重建后 `/health` 正常，`mix2api/1.6.2`。

- 版本号：`mix2api/1.6.2`；镜像 `ghcr.io/ayeaaaa/mix2api:v1.6.2`。

## English summary

`mix2api` v1.6.2 restores the opt-in gate for the Raccoon exit: the card and account entry appear only after "Enable Raccoon" is checked in Settings → Raccoon, and the setting now explains that. The v1.6.1 `/auth/callback` OAuth fix is retained. All 284 test suites pass; the multi-arch image is published as `ghcr.io/ayeaaaa/mix2api:v1.6.2` and `:latest`.
