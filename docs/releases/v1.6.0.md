# mix2api v1.6.0

新增第四个出口 `raccoon`（商汤小浣熊），原生 Python 单进程实现；WorkBuddy 国际版 / 国内版与华为云 CodeArts 的行为保持不变。

## 这个版本做了什么

- **小浣熊（Raccoon）第四出口**：新增 `raccoon` realm，看板顶部变为 `国际版 / 国内版 / CodeArts / 小浣熊`。模型发现、token 续期、账号池、并发 / 冷却 / 失败切换、聊天 SSE 和回环 OAuth 全部在 `app/` 进程内完成，不需要 Node sidecar，也没有新增第三方依赖。
- **两种接入方式**：导入桌面客户端 `auth.json`，或使用本机回环 OAuth。首次成功导入会自动启用出口。
- **9 个原始模型 ID**：`raccoon-090dd3`、`raccoon-19b265`、`raccoon-405a1c`、`sn-sensenova-6-8-flash`、`sn-sensenova-6-8-flash-lite`、`sn-glm-5-3`、`sn-kimi-k3`、`sn-glm-5-3-flash`、`sn-deepseek-v4-1-flash-1017`。`/v1/models?realm=raccoon` 只返回裸 ID，不加任何提供商前缀。
- **协议与能力**：chat 非流式与 SSE、工具调用、视觉模型的图片输入（OpenAI `image_url`、Responses `input_image`、Anthropic `image`）；`/v1/responses` 与 Anthropic Messages（需显式开启）复用现有适配层。
- **多账号与代理**：多账号池、并发控制、会话粘性、429/5xx 冷却后自动换号、401/403 先强制续期一次再重试；账号级代理槽与 WorkBuddy / CodeArts 共用 `wb_upstream_pool` 的连接复用、代理认证和 `no_proxy`。
- **账号管理**：看板支持导入、浏览器授权、备注、任务开关（为后续自动化预留；v1.6.0 没有签到 / 成长任务）、单账号测试、启停、清冷却、删除和刷新模型目录。
- **用量**：每行记 `realm=raccoon`、上游账号 UID 和 `cost_policy=raccoon:unpriced`；token 数按上游返回记录。Raccoon 账号卡片/账号表没有积分列；通用用量表沿用字段，积分显示 `0.00`、估算价格显示 `—`。小浣熊没有积分 / 签到接口。
- **Key 与出口**：API Key 可以绑定 `raccoon` 出口，也可以留空跟随面板默认出口；Key 的模型限制和允许账号白名单照常生效。
- **不合并 `realm=all`**：`/v1/models?realm=all` 仍只含 WorkBuddy 模型，不把 Raccoon 混进来；出口由 Key 或面板默认出口选择，所以 v1.6.0 不需要提供商前缀。
- **暂不支持**：扫码登录、手机号 / 密码登录（需要二维码渲染和 AES-128-CFB，后续版本再补）。回环 OAuth 要求浏览器与网关共享 loopback，远程部署请导入 `auth.json`。

## 添加小浣熊账号

1. 打开看板 →「设置 → 小浣熊接入」，勾选「启用小浣熊出口」并保存（首次成功导入账号会自动启用）。
2. 切到小浣熊视图，点「添加账号」：
   - **导入 auth.json**：粘贴桌面客户端 `auth.json` 原文，也接受 auth 响应里的 `{"data": {...}}`；网关解析 JWT 得到 UID / 有效期后原子落盘。
   - **浏览器授权**：点「开始浏览器授权」生成官方授权链接；浏览器和网关必须在同一台机器、共享 `127.0.0.1` 回环，授权完成后页面会自动轮询。若浏览器回调打不到网关，可把完整回调地址粘贴到「远端回调」中转。state 一次性有效，300 秒过期。
3. 在「设置 → API Key 与出口绑定」里新建 Key，出口选 `小浣熊`，或留空跟随顶部默认出口。

## English summary

`mix2api` v1.6.0 adds Raccoon (SenseTime 小浣熊) as a fourth exit, implemented natively in Python with no Node sidecar and no new dependencies. It supports importing the desktop client's `auth.json` and a loopback OAuth flow, a multi-account pool with concurrency, cooldown and failover, account proxy slots, notes, a task toggle, per-account tests, enable/disable, cooldown clearing and delete, token refresh and catalog refresh. `/v1/models?realm=raccoon` returns nine original bare model ids, and the gateway supports chat (non-streaming and SSE), tool calls, image input on vision models, Responses and Anthropic Messages (when explicitly enabled). Usage rows carry `realm=raccoon` and `cost_policy=raccoon:unpriced`; Raccoon exposes no credits or check-in. `realm=all` remains WorkBuddy-only, and v1.6.0 does not include QR or phone/password login. All 284 test suites pass (212 Python + 72 JS).
