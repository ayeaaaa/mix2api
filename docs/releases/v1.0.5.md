# mix2api v1.0.5

v1.0.4 之后的补丁版：CodeArts 模型对外使用 `YYLS/` 命名空间，并补齐 DeepSeek-V4.1 的推理档位。

## 这个版本做了什么

- **CodeArts 模型命名空间**：CodeArts 模型对外统一为 `YYLS/<模型名>`，例如 `YYLS/GLM-5.2`、`YYLS/deepseek-v4.1-flash`。`/v1/models?realm=codearts` 返回带前缀的 ID；请求带 `YYLS/` 时自动路由到 CodeArts，并在发给华为前剥掉前缀。这样 WorkBuddy 和 CodeArts 的同名模型可以同时存在，不会串出口。
- **保留兼容**：Key 绑定 CodeArts 或当前出口是 CodeArts 时，裸模型名仍然可用；`YYLS/` 只是显式选择 CodeArts 的方式。
- **冲突保护**：Key 绑定到国际版/国内版，或请求显式指定 `?realm=intl|cn` 时，带 `YYLS/` 的模型会直接 400，不会偷偷绕到 CodeArts。
- **DeepSeek-V4.1 推理档位**：`deepseek-v4.1-flash` 和 `deepseek-v4.1-flash-1017` 在 `/v1/models` 宣告 `reasoning_efforts`：`none / low / medium / high / xhigh / max`。这是用上游校验错误确认的；`auto` 会被上游拒绝，网关现在本地直接 400 并列出允许值。
- **不猜默认档**：上游没有声明默认 `reasoning_effort`，所以不写 `reasoning_default_effort`，也不宣告 `canDisableThinking`（实测 `none` 仍会产生 reasoning tokens）。

## 升级

- 直接替换镜像或代码即可，无数据迁移；默认端口仍是 `58675`。
- 客户端如果缓存了旧的 CodeArts 裸模型 ID，刷新模型列表后会看到 `YYLS/...`；裸 ID 在 CodeArts 出口下仍兼容。
- 需要强制走 CodeArts 时使用 `YYLS/<模型名>`，即使当前面板出口是国际版/国内版。

## 验证

- 243 个测试套件全过。
- `/v1/models?realm=codearts` 返回 `YYLS/...`，并包含 `reasoning_efforts`。
- `YYLS/GLM-5.2` 的 chat / responses / messages 请求都路由到 CodeArts，响应 `model` 保留 `YYLS/` 前缀，上游收到裸 `GLM-5.2`。
- Key 绑定国际版时请求 `YYLS/GLM-5.2` 返回 400。
- `YYLS/deepseek-v4.1-flash` + `reasoning_effort=max` 正常；`auto` 返回 400，错误信息列出六个允许值。

## Docker 镜像

已发布到 GitHub Container Registry，支持 `linux/amd64` 与 `linux/arm64`：

```bash
docker pull ghcr.io/ayeaaaa/mix2api:v1.0.5
docker pull ghcr.io/ayeaaaa/mix2api:latest
```

直接运行：

```bash
docker run -d --name mix2api -p 58675:58675 \
  -v "$PWD/data/accounts:/app/accounts" \
  -v "$PWD/data/usage:/app/usage" \
  ghcr.io/ayeaaaa/mix2api:v1.0.5
```

或用本包里的 `deploy/docker-compose.image.yml`：

```bash
cd deploy
docker compose -f docker-compose.image.yml up -d
```

## English summary

`mix2api` v1.0.5 exposes CodeArts models under the `YYLS/` namespace, so CodeArts and WorkBuddy models with the same bare id can coexist. `/v1/models?realm=codearts` returns prefixed ids; `YYLS/` requests route to CodeArts and the prefix is stripped before the upstream call, while bare ids remain compatible when the key or current exit is CodeArts. A conflicting key/exit binding returns 400. DeepSeek-V4.1-Flash and `-1017` now advertise `reasoning_efforts` `none / low / medium / high / xhigh / max`; `auto` is rejected locally with a 400 that lists the allowed values. The multi-arch image is published as `ghcr.io/ayeaaaa/mix2api:v1.0.5` and `:latest`.
