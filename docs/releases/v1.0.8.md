# mix2api v1.0.8

v1.0.7 之后的补丁版：补齐 1–5 项收尾，主要是客户端参数别名、账号运营和图片边角。

## 这个版本做了什么

- **思考参数别名**：`thinking: {type: enabled|disabled}`、`enable_thinking: true|false`、camelCase `reasoningEffort` 现在都会归一化成 CodeArts 的 `reasoning_effort`；`enabled → high`、`disabled → none`。始终思考的 `glm-5.3-flash` 收到 `none` 时回退到 `low`，不会整条请求失败。
- **更多参数透传**：新增 `top_k`、`parallel_tool_calls`；连同 v1.0.6 的 `stop` / `response_format` / penalties / `seed` 一起透传。
- **工具能力抽测**：用真实上游验证了 GLM-5.2、Qwen3-VL-235B 的 tool_calls 和 `parallel_tool_calls`；目录继续宣告 `supports_tool_calls: true`。
- **单账号重新登录**：CodeArts 账号行新增「重新登录」，直接打开 OAuth；同 UID 会更新现有账号，不会新增重复项。
- **刷新积分**：CodeArts 设置区新增「刷新积分」，后端强制刷新所有启用账号的积分快照，不再依赖 60 秒缓存。
- **图片边角**：`image_url.detail` 会保留；tool_result 里的图片分片不会被压平；远程 URL 原样透传（能否抓取取决于上游）。

## 升级

- 直接替换镜像或代码即可，无数据迁移；默认端口仍是 `58675`。
- 客户端只发 `thinking` / `enable_thinking` 也能正常控制推理档位。
- `glm-5.3-flash` 仍然只支持 `low / high / max`，不能关闭思考。

## 验证

- 243 个测试套件全过。
- 真实上游验证 `top_k`、`parallel_tool_calls` 被接受；GLM-5.2 / Qwen3-VL-235B 都返回了 tool_calls。
- 本地验证 `thinking` / `enable_thinking` / `reasoningEffort` 映射。
- 图片测试覆盖 `detail`、tool_result 图片和远程 URL 保留。

## Docker 镜像

已发布到 GitHub Container Registry，支持 `linux/amd64` 与 `linux/arm64`：

```bash
docker pull ghcr.io/ayeaaaa/mix2api:v1.0.8
docker pull ghcr.io/ayeaaaa/mix2api:latest
```

直接运行：

```bash
docker run -d --name mix2api -p 58675:58675 \
  -v "$PWD/data/accounts:/app/accounts" \
  -v "$PWD/data/usage:/app/usage" \
  ghcr.io/ayeaaaa/mix2api:v1.0.8
```

或用本包里的 `deploy/docker-compose.image.yml`：

```bash
cd deploy
docker compose -f docker-compose.image.yml up -d
```

## English summary

`mix2api` v1.0.8 finishes the 1–5 follow-up: `thinking` / `enable_thinking` / `reasoningEffort` normalize to `reasoning_effort`; `top_k` and `parallel_tool_calls` are forwarded; per-account re-login and credit refresh are available in the CodeArts table; and image `detail`, tool_result image parts and remote URLs are preserved. Tool calls were verified against the real upstream for GLM-5.2 and Qwen3-VL-235B. The multi-arch image is published as `ghcr.io/ayeaaaa/mix2api:v1.0.8` and `:latest`.
