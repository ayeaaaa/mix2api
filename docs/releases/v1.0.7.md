# mix2api v1.0.7

v1.0.6 之后的补丁版：补齐 GLM 系列推理档位，并把 CodeArts 保活改成 30 分钟巡检。

## 这个版本做了什么

- **GLM 推理档位**：根据上游校验结果，`GLM-5.2`、`GLM-5.2-SFT-Harmony`、`GLM-5.3` 支持 `none / minimal / low / medium / high / xhigh / max`；`glm-5.3-flash` 只支持 `low / high / max`，且上游明确「始终思考」，所以额外宣告 `reasoning_can_disable: false`、`always_reasoning: true`。
- **本地校验**：这些模型的 `reasoning_effort` 现在在网关本地校验；`auto` 或不在列表里的值直接 400，并列出允许值，不再把上游错误吞成 502。
- **30 分钟保活**：CodeArts 每 30 分钟检查一次 Token，快过期的账号主动续期；22:00 仍随 WorkBuddy 巡检。没有过期账号时不发上游请求。
- **其余对齐项**沿用 v1.0.6：参数透传、模型限额/工具元数据、图片 400、账号备注/任务开关/测试、`realm=all`、签到历史。

## 升级

- 直接替换镜像或代码即可，无数据迁移；默认端口仍是 `58675`。
- 客户端刷新一次 `/v1/models` 即可看到 GLM 系列的 `reasoning_efforts`。
- `glm-5.3-flash` 不接受 `none`/`minimal`/`medium`/`xhigh`/`auto`，只接受 `low`/`high`/`max`。

## 验证

- 243 个测试套件全过。
- 上游探测结果：
  - `GLM-5.2` / `GLM-5.2-SFT-Harmony` / `GLM-5.3`：`none, minimal, low, medium, high, xhigh, max`
  - `glm-5.3-flash`：`low, high, max`（始终思考）
  - `deepseek-v4.1-flash` / `-1017`：`none, low, medium, high, xhigh, max`
- 本地校验：`GLM-5.2` 的 `minimal` 通过；`glm-5.3-flash` 的 `medium` 返回 400。
- CodeArts 30 分钟保活逻辑已接入调度器。

## Docker 镜像

已发布到 GitHub Container Registry，支持 `linux/amd64` 与 `linux/arm64`：

```bash
docker pull ghcr.io/ayeaaaa/mix2api:v1.0.7
docker pull ghcr.io/ayeaaaa/mix2api:latest
```

直接运行：

```bash
docker run -d --name mix2api -p 58675:58675 \
  -v "$PWD/data/accounts:/app/accounts" \
  -v "$PWD/data/usage:/app/usage" \
  ghcr.io/ayeaaaa/mix2api:v1.0.7
```

或用本包里的 `deploy/docker-compose.image.yml`：

```bash
cd deploy
docker compose -f docker-compose.image.yml up -d
```

## English summary

`mix2api` v1.0.7 adds verified reasoning levels for the GLM family: `GLM-5.2` / `GLM-5.2-SFT-Harmony` / `GLM-5.3` accept `none / minimal / low / medium / high / xhigh / max`, while `glm-5.3-flash` accepts only `low / high / max` and is always-reasoning. The gateway now validates these values locally and returns 400 with the allowed list for `auto` or unknown values. CodeArts token keepalive runs every 30 minutes (and still on the 22:00 sweep). The multi-arch image is published as `ghcr.io/ayeaaaa/mix2api:v1.0.7` and `:latest`.
