# mix2api v1.1.1

v1.1.0 之后的补丁版：同步 `workbuddy2api-hub` v1.10.2–v1.10.4 的 CodeArts 与目录修复。

## 这个版本做了什么

- **CodeArts OAuth 回调修复**：华为云会把授权链接里的 `ticket_id` 改名成 `state` 回传（形如 `<32 hex>.pkg`）。现在回调同时认 `ticket_id`、`secret` 与 `state`，浏览器授权不再必然失败；陌生 `state` 仍然拒绝，不会登进别人的会话。
- **CodeArts 非流式聚合释放账号**：非流式响应在 `finally` 关闭上游流，修掉背靠背请求提前释放账号、导致并发竞争的问题。
- **价格快照同步**：`pricing/pricing.json` 更新到上游 v1.10.4 的现状。
- **模型目录 / 成长任务**：`wb_catalog.py`、`wb_tasks.py` 与上游 v1.10.4 对齐；成长中心新增任务、Buddy 开盲盒与小程序链式任务已包含。
- **看板模型归属**：最近请求/性能表里的国际版独占模型列表补上 `gpt-6.1-sol`、`gpt-6-sol`、`gpt-6-luna`、`gemini-3.8-flash` 等新模型。

## 升级

- 直接替换镜像或代码即可，无数据迁移；默认端口仍是 `58675`。
- 默认打开 `/` 就是新面板；旧界面保留在 `/classic`。
- 客户端 API 地址、Key、模型 ID 不变。

## English summary

`mix2api` v1.1.1 syncs the `workbuddy2api-hub` v1.10.2–v1.10.4 fixes: CodeArts OAuth callbacks now accept the upstream `state` alias, non-stream CodeArts aggregation closes its upstream stream in `finally`, the pricing snapshot and model/task catalog are aligned, and the dashboard's international-only model list covers the new model ids. No API or data migration is needed; 246 test suites pass.
