# mix2api v1.4.0

同步 WorkBuddy 上游 v1.10.11，保留 mix2api 品牌、新 UI、媒体生成和 CodeArts 官方倍率。

## 上游更新

- 账号分组、账号表分页、排序与轮询指纹跳过
- 添加账号时可指定或随机分配登录出口代理槽
- 风控连坐暂停保护可自定义时长并支持立即解除
- CodeArts 参数校验、413 响应与用量写入锁修复
- 默认使用新导航布局
- v1.10.10–v1.10.11 的其余修复

## mix2api 保留

- mix2api 品牌与 `WorkBuddy` 产品文案分离
- `/` 新 UI、`/classic` 旧壳
- 不使用 Alibaba 默认配色，默认 Claude 主题
- 媒体生成模块
- CodeArts 官方 10 个模型与积分倍率（含 DeepSeek 高峰/错峰）
- CodeArts `credits_auto_claim` 默认开启
- 本地部署端口 `58675`

## 验证

- 273 个测试套件全过
- 本地容器重建后 `/`、`/classic` 正常
- CodeArts 4 个账号健康

## English summary

`mix2api` v1.4.0 syncs WorkBuddy upstream v1.10.11 (account groups, pagination, login proxy slots, restriction-hold settings, CodeArts/413 fixes, new navigation) while preserving mix2api branding, the `/classic` shell, media generation, and the official CodeArts model credit multipliers. 273 test suites pass.
