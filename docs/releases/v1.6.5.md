# mix2api v1.6.5

小浣熊任务与福利、登录奖励自动领取，以及 CodeArts 账号状态、积分调度和模型选择修复。

## 这个版本做了什么

### 小浣熊（Raccoon）

- **积分任务**：接入网页端 `GET /api/web/points/v1/tasks`，在「任务与福利」页显示注册、桌面端、移动端任务状态；被邀请账号还会显示 7 日活跃、首次付费等专属任务。
- **任务与福利页**：新增独立的「小浣熊任务与福利」区块，包含账号数、可用积分、今日消耗、待领取登录奖励和任务表；账号表不再重复展示任务状态和领取按钮。
- **登录奖励**：任务页可按账号领取桌面端登录奖励（3000 分）和移动端登录奖励（3000 分）。移动端使用官方移动端接口 `/api/web/mobile/v1/login/points/grant`，请求头 `X-Client-Platform: app-android`、`X-Client-Version: v1.1.0`。
- **自动领取**：任务页新增「自动领取登录奖励」开关，默认关闭；开启后，概览刷新时自动领取未完成的桌面端/移动端奖励，尊重账号的任务开关，并做 5 分钟节流。
- **真实账号验证**：桌面端 `3284 → 6284`，移动端 `6284 → 9284`；重复领取幂等。小浣熊没有签到接口。

### CodeArts

- **保留手动停用**：新增 `manual_disabled` 状态；token 续期、重新登录和模型发现不再把手动停用的账号自动启用。`/v1/models` 也不再刷新已停用账号的 token。
- **零积分账号**：已知 `remain <= 0` 的账号不再参与调度；上游返回「积分已耗尽」400 时，标记该账号并自动换到下一个账号，而不是把 400 直接返回给客户端。签到拿到新积分后会清除旧的零积分快照。
- **模型选择**：智能体/一键配置的模型下拉补入 CodeArts 模型（含小写 `deepseek-v4.1-flash-1017`）；CodeArts `/v1/models` 继续返回该模型。
- **临期积分优先**：CodeArts 设置新增「临期积分优先」（默认开启）。有临期积分（含每日签到 24 小时积分）的账号优先接请求；这只影响账号调度，不改变上游积分包扣减顺序。实测上游在同一账号内已经优先扣临期积分：一次请求 `used +1.71`，`expiring -1.71`。
- **上游 400 处理**：积分耗尽错误现在会触发换号；所有账号都耗尽时返回可读的 400，而不是重复命中同一个账号。

### 其他

- 修复版本相关的 README 测试计数与发布说明。
- 无配置/账号格式破坏性变化；CodeArts 旧 state 缺少 `manual_disabled` 时按 `reason == "manual disable"` 兼容。

## English summary

`mix2api` v1.6.5 adds Raccoon points tasks, the Raccoon tasks-and-rewards page, desktop/mobile login rewards (including opt-in auto-claim), and fixes CodeArts account and scheduling behavior. Manually disabled CodeArts accounts now stay disabled across token refresh, model discovery and re-login; known zero-credit accounts are no longer dispatched, and an upstream credit-exhausted 400 is treated as account-level and fails over to another account. The agent one-click model picker now includes CodeArts models such as `deepseek-v4.1-flash-1017`. A CodeArts "expiring credits first" account scheduling option is enabled by default; upstream already consumes expiring credits within an account. All 285 suites pass (212 Python + 73 JS).
