## Change

- Exit-qualified model IDs (`intl/...`, `cn/...`, `codearts/...`, `raccoon/...`)
  route Chat, Responses, and Messages to the named exit while sending the bare
  upstream ID to the provider.
- `GET /v1/models?realm=gateway` returns the all-exit catalog; `realm=all` stays
  WorkBuddy `intl`/`cn` only.
- Key allow-lists match canonical and upstream IDs; a bound key realm remains
  hard policy.
- Usage keeps the upstream model for billing and records canonical
  `requested_model` for analytics.
- WorkBuddy credit packages are paged (200/page, up to 10 pages), include
  used/expired statuses, and prefer the official cumulative summary totals.
