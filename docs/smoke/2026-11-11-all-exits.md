## Observations

- A bare `/usage` request without `realm` can default to the configured active realm and hide rows from another realm; `realm=cn`, `realm=all`, or per-provider filters returned the expected rows. This matches v1.6.5: `_get_v1_usage` resolves `?realm` → `X-Realm` → `CURRENT_REALM`, and v2 uses the live active-realm service, so it is documented parity rather than a defect.
- Free WorkBuddy CN usage still reported small `credit` values (0.02–0.08) despite `free=true`. v1.6.5 `_extract_usage` records the upstream `usage.credit` unchanged (default `0`) and has no free-model suppression; v2 does the same and adds `free=true` only as an attribution marker. The credit is upstream-provided; no code change.
- CodeArts usage has no credit value in v2 rows; Raccoon uses point credit; provider semantics are not mixed.
