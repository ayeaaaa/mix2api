## Change

- Added Doubao Work as the fifth exit (`realm=doubao`, canonical
  `doubao/<model>`), including 12 models, cookie/device import, account pool,
  session affinity, concurrency/cooling, proxy slots, SSE/non-streaming chat,
  multi-turn conversations, dashboard integration, credits/tasks, and an
  opt-in CST check-in scheduler.
- Added `POST /doubao/accounts/probe` to store the desktop `landing/checkin`
  query/UA and replay it for reward submission. The probe value is persisted
  but never returned through the account view.
- API keys can bind to `gateway` (all providers); `/v1/models` defaults to the
  all-exit catalog and Chat/Responses/Messages may use any exit. Concrete exit
  bindings and `realm=all` semantics are unchanged.
