## Change

- CodeArts panel OAuth callbacks with an authenticated `session_id` no longer
  enforce Huawei's rewritten `state`, fixing “authorization state mismatch”.
  Direct browser callbacks without `session_id` still require exact
  `state`/`ticket_id` matching.
- Adding a CodeArts account now only generates and displays the authorization
  link; it no longer opens a browser window automatically. A Copy link action
  was added, and relayed follow-up links are left for the user to open.
