## Change

When a China account has a successful `lastCheckin` record for today, the Buddy
check-in badge now shows Claimed even if an earlier scheduler retry failed. The
failed attempt remains visible in the activity history. The dashboard asset
hash/size metadata and the JS regression suite were updated accordingly.
