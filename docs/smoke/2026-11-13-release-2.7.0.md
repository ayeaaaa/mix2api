## Changes

- **CodeArts credit:** samples the account's cumulative used-credit baseline
  before chat, force-refreshes statistics afterward, and writes the delta to
  usage. Explicit upstream credit is not double-counted; sampling failures do
  not block chat; concurrent requests share a high-water mark.
- **Key daily token limit:** `daily_token_limit` in millions, enforced before
  the concurrency slot, returns `403 permission_error`, uses the Anthropic
  envelope for `/v1/messages`, and has a dashboard field/badge.
- **Tool schema hardening:** WorkBuddy and CodeArts share
  `providers.HardenSchemaKeywords` for numeric/boolean strings, enum/examples,
  string keywords, additionalProperties, and null keywords, fixing upstream
  code 11129.
