## v1 update-check compatibility note

The v1.6.5 update checker defaults to `ayeaaaa/mix2api` and treats `v2.0.0` as
the latest stable release. v1's installer looks for
`workbuddy2api-hub-v2.0.0.zip`, which this release does not contain, so a v1
deployment with update checks enabled may see an update that cannot install.
This was accepted when choosing to publish v2 from the existing repository.
